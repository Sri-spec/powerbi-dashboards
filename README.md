### CO2 Emissions by Vehicle Analysis

**Objective**: Analyze environmental impact of different vehicle types and powertrains to inform sustainability policies.

**Key Visualizations**:
- **Emissions by Fuel Type**: Breakdown across Petrol, Diesel, Electric, Hybrid
- **Powertrain Analysis**: Transmission type impact on emissions
- **Key Influencers**: AI-driven factors affecting emission levels
- **Top Segments**: High and low emission vehicle categories

**Data Insights**:
- Petrol vehicles: 51.2% of analyzed fleet (535K vehicles)
- Diesel: 24.93% (261K vehicles)
- Electric/Hybrid: Growing but still small percentage
- Transmission type significant factor in emission levels

**Analysis Techniques**:
- **AI Insights**: Power BI's Key Influencers visual to identify emission drivers
- **Segmentation**: Clustering vehicles by emission characteristics
- **Comparative Analysis**: Fuel type and powertrain combinations
- **Trend Analysis**: Tracking shifts toward cleaner technologies

**Policy Implications**:
- Support for electric vehicle adoption
- Transmission technology improvements
- Fuel type transition strategies
- Emission reduction targets by vehicle category

**Technical Highlights**:
- AI-powered Key Influencers analysis
- Advanced segmentation algorithms
- Multi-dimensional filtering (fuel type, transmission, powertrain)
- Large dataset handling (535K+ vehicles)

## 📊 Design Principles Applied

### 1. User-Centered Design
- Understand audience needs and technical proficiency
- Design for specific use cases (executive dashboards vs. operational reports)
- Provide appropriate level of detail for user role

### 2. Visual Best Practices
- **Chart Selection**: Bar charts for comparison, line charts for trends, maps for geography
- **Color Usage**: Meaningful color (red for negative, green for positive), colorblind-friendly palettes
- **White Space**: Avoid clutter, allow visuals to breathe
- **Typography**: Readable fonts, appropriate sizes, clear hierarchy

### 3. Interactivity
- **Filters**: Allow users to explore data dimensions
- **Drill-Through**: Deep dives into specific metrics
- **Tooltips**: Additional context without cluttering visuals
- **Bookmarks**: Saved views for different scenarios

### 4. Performance
- **Query Optimization**: Efficient DAX measures
- **Visual Reduction**: Only essential visuals per page
- **Data Model**: Star schema for fast queries
- **Incremental Refresh**: Large dataset handling

### 5. Accessibility
- **Color Contrast**: WCAG 2.1 AA standards (4.5:1 ratio)
- **Alt Text**: Descriptive text for screen readers
- **Tab Order**: Logical keyboard navigation
- **Visual Indicators**: Not relying solely on color
